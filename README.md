# engineering-lab-projects
Collection of university lab projects in Electronics, Digital Circuits, Signals & Systems 2 and related engineering courses. Includes reports, tasks, simulations, and measurement results.

## Technical Document Management Approach
All lab materials are organized to ensure traceability and structured access:
- **Folder structure**: one per course, separating requirements (Task PDFs) and deliverables (Report PDFs).
- **Naming conventions**: standardized `Lab_X_Task` and `Lab_X_Report` filenames for easy version tracking.
- **Documentation**: each folder includes a detailed README describing objectives, tools, methods, and skills demonstrated.
- **Version control**: all updates tracked via Git for reproducibility and transparent change history.
